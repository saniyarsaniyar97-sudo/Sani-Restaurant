# Sani-Restaurant – Online-Speisekarte & Bestellformular

Ein einfaches, interaktives Webprojekt für eine Restaurant-Website. Benutzer können die Speisekarte einsehen, Gerichte über Checkboxen auswählen, ihre Kontaktdaten eingeben und den Gesamtpreis ihrer Bestellung direkt berechnen lassen.

## 🚀 Funktionen

* **Interaktive Speisekarte:** Übersichtliche Preistabelle für Speisen (Pizza, Burger, Sushi, Fisch).
* **Dynamische Preisberechnung:** Automatische Summation des Gesamtpreises anhand der ausgewählten Gerichte via JavaScript.
* **Formularvalidierung:**
  * Namensfelder erlauben nur Buchstaben (inkl. deutscher Umlaute `ä`, `ö`, `ü` und `ß`).
  * Überprüfung, ob mindestens ein Gericht ausgewählt wurde.
* **Live-Bestellbestätigung:** Zeigt nach dem Absenden eine Zusammenfassung der Bestellung (Name, Lieferadresse, gewählte Speisen und Gesamtpreis) direkt auf der Seite an, ohne neu zu laden.
* **Ansprechendes Design:** Benutzerdefiniertes CSS mit farblichen Akzenten und formatierten Tabellen.

## 📁 Projektstruktur

```
.
├── index.html   # Hauptstruktur der Webseite inkl. HTML-Formular & JavaScript-Logik
├── style.css    # Layout, Farben und Styling der Speisekarte und Formulare
└── README.md    # Projektdokumentation
```

## 💻 Installation & Nutzung

1. **Lade die Dateien herunter** oder klone das Repository via **GitHub**.
2. Stelle sicher, dass `index.html` und `style.css` im **selben Ordner** liegen.
3. Öffne das Projekt in deinem Code-Editor (z. B. **VS Code**).
4. Öffne die Datei `index.html` in einem beliebigen Webbrowser (z. B. Chrome, Firefox, Edge, Safari).

## 🛠️ Verwendete Technologien & Tools

* **HTML5 (`index.html`):** Strukturierung von Inhalt, Tabellen und Formularen.
* **CSS3 (`style.css`):** Styling und Layout-Gestaltung.
* **JavaScript (Vanilla JS):** Event-Handling, DOM-Manipulation und Preisberechnung.
* **VS Code (Visual Studio Code):** Entwicklungsumgebung / Code-Editor.
* **GitHub:** Versionsverwaltung und Hosting des Quellcodes.
